Title: Unauthenticated websites can exfiltrate arbitrary local files through the EverOS API

Summary: EverOS's unauthenticated FastAPI memory API combines two insecure
defaults — file_uri_allow_dirs=[] treats an empty allowlist as "allow any
readable file" for file:// ingestion, and CORS defaults to allow_origins=["*"]
with allow_credentials=True. Any website a victim visits can read arbitrary
local files (≤50 MB/item) via POST /api/v2/memory/add + /memory/search and
write attacker-chosen memories. Demonstrated end-to-end in headless Chromium
from a cross-origin hostname.

Reproduction package (report + evidence + runnable PoC):
https://github.com/Teycir/everos-cors-file-exfil
